# Archived legacy admin application

This Struts-based admin application belongs to the original card-engine project. It is retained for historical reference only: it is excluded from the PeerVault Maven reactor and Compose deployment, and its endpoints must not be exposed. Use the authenticated `/api/admin/**` PeerVault API instead.

Do not enable or deploy this module until its framework and dependencies have been upgraded, its authentication/authorization model has been reviewed, and it has a maintained integration test suite.
